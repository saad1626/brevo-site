Put your website images in this folder (client/public/images) with these exact names:

hero.jpg          - Home page, top section (laptop image)
feature-1.jpg     - Home page, "Build Your List" card
feature-2.jpg     - Home page, "Drag and Drop Editor" card
feature-3.jpg     - Home page, "Automation" card
growth.jpg        - Home page, "Campaign Success" image
pricing.jpg       - Home page, Starter plan phone image
about.jpg         - About page, tablet image
contact.jpg       - Contact page, laptop image

If an image is missing, the website shows a grey box instead (it will not break).
Run "npm run build" again after adding images.
